Política de privacidad de DAAR Player

Fecha de entrada en vigor: 17 de octubre de 2026
Responsable: Edgar Arjona
País: Panamá
Contacto: edgararjona15@gmail.com

DAAR Player es un reproductor multimedia independiente. No proporciona, vende, aloja ni recomienda canales, películas, series, listas de reproducción ni credenciales. El usuario debe usar únicamente contenido y fuentes para los que tenga autorización.

1. Alcance

Esta política aplica a la aplicación Android DAAR Player, identificada por el paquete com.daar.player, cuando el usuario configura y reproduce sus propias fuentes multimedia.

2. Información tratada

Según las funciones usadas, la aplicación puede tratar localmente nombres y direcciones de servidores Xtream Codes, M3U, WebDAV, SMB y Jellyfin; nombres de usuario, contraseñas o tokens; catálogos, EPG, portadas, subtítulos y metadatos; favoritos, historial, progreso, perfiles, preferencias y control parental; archivos descargados por decisión del usuario; e información básica de red local y dispositivos compatibles necesaria para Google Cast, DLNA o acceso a un NAS.

Las credenciales se almacenan cifradas en el dispositivo y se transmiten directamente al servidor configurado por el usuario. DAAR Player no opera un servidor propio de cuentas ni sincroniza dichas credenciales con el responsable.

3. Finalidades

La información se usa para autenticar conexiones solicitadas por el usuario, obtener y mostrar catálogos, EPG y metadatos, reproducir, enviar o descargar contenido, conservar preferencias y progreso local, y mostrar diagnósticos de conexión o reproducción sin registrar contraseñas.

4. Servicios y servidores de terceros

Cuando el usuario configura un proveedor, NAS o servidor multimedia, DAAR Player se comunica directamente con ese servicio. El responsable no controla el tratamiento de datos realizado por el proveedor elegido.

La aplicación puede incorporar Google Cast para descubrir y controlar dispositivos compatibles. Consulta la declaración de datos de Google Cast.

5. Conexiones HTTP y HTTPS

DAAR Player admite HTTP y HTTPS porque algunas fuentes configuradas por los usuarios no ofrecen HTTPS. Si el usuario elige HTTP, credenciales, metadatos y contenido pueden viajar sin cifrado. Se recomienda usar HTTPS siempre que el servidor lo permita.

6. Conservación y eliminación

Los perfiles, credenciales, historial, preferencias y descargas permanecen en el dispositivo hasta que el usuario los elimina, borra los datos de la aplicación o la desinstala. Las conexiones y sus datos locales asociados pueden eliminarse desde la aplicación. DAAR Player no crea ni conserva cuentas en un servidor del responsable.

7. Compartición y venta

El responsable no vende información personal. La aplicación transmite información únicamente al servidor o dispositivo seleccionado por el usuario y a los componentes descritos en esta política cuando son necesarios para la función usada.

8. Menores

DAAR Player no está dirigida específicamente a menores. El adulto responsable debe controlar las fuentes configuradas y puede usar el control parental local disponible en la aplicación.

9. Seguridad

Se aplican medidas como cifrado local de credenciales, validación normal de certificados HTTPS, exclusión de datos sensibles en registros técnicos y desactivación de copias de seguridad de datos privados. Ningún método es infalible, especialmente si el usuario selecciona HTTP o un servidor externo.

10. Derechos y contacto

Para consultas de privacidad escribe a edgararjona15@gmail.com. La información almacenada exclusivamente en el dispositivo puede eliminarse desde DAAR Player, desde los ajustes de Android o desinstalando la aplicación.

11. Cambios

Esta política puede actualizarse cuando cambien las funciones, los SDK o los requisitos aplicables. La versión vigente mostrará su fecha de entrada en vigor en esta misma página.
